# Avisos e licenças de terceiros — CPU Express consolidado

Inventário de **144 pacotes de registry** na união dos grafos Cargo de `x86_64-pc-windows-gnu` e `x86_64-pc-windows-msvc`.

Versões conferidas contra Cargo.lock. As expressões SPDX abaixo reproduzem o campo `license` do metadata; os textos de licença e avisos foram preservados sem alteração. Este grafo inclui dependências de compilação e pode incluir pacotes que não contribuam código ao executável; a lista não é uma análise de símbolos do binário.

O código próprio do CPU Express e seus desenhos procedurais estão cobertos por [LICENSE](LICENSE). A arte procedural própria foi reunida com os demais módulos do CPU Express; nenhum recurso do APK de Tiny Rails foi incluído no jogo.

## Origem dos textos complementares

Quando o pacote publicado não continha sua licença de código, o coletor usou o repositório upstream no commit declarado por `.cargo_vcs_info.json`. URLs, revisões, nomes, tamanhos e SHA-256 de cada texto estão em [licenses/manifest.json](licenses/manifest.json). Arquivos NOTICE/COPYRIGHT encontrados nos pacotes e NOTICE encontrado na consulta upstream também são incluídos.

- **Origem alternativa documentada:** Alguns pacotes egui 0.37.0 declaram o commit 7c0b40402271e8d40cda69f87cf3c2617c2e4382, que estava indisponível no upstream em 13/11/2026. Seus textos complementares foram recuperados no commit 841a328ba2dd8f6996beb7189ebb7fc00e668a2a, alvo do tag de release 0.37.0. Essa origem alternativa é registrada, sem atribuir os textos ao commit indisponível. Fonte: [https://github.com/emilk/egui](https://github.com/emilk/egui/tree/841a328ba2dd8f6996beb7189ebb7fc00e668a2a).
- **Origem alternativa documentada:** winapi-x86_64-pc-windows-gnu 0.4.0 não inclui textos de licença nem .cargo_vcs_info.json no pacote publicado. Os textos MIT/Apache do mesmo projeto foram recuperados no commit 796a8e6c2971dc2ff1bcff166e6671284f9b5b6b, tag 0.3.9 e revisão publicada da crate winapi 0.3.9 que depende desse pacote. A origem é complementar; não é apresentada como revisão de publicação da crate GNU 0.4.0. Fonte: [https://github.com/retep998/winapi-rs](https://github.com/retep998/winapi-rs/tree/796a8e6c2971dc2ff1bcff166e6671284f9b5b6b).

## Biblioteca padrão Rust e toolchain Windows

Os avisos distribuídos com a biblioteca padrão Rust estão em [COPYRIGHT-library.html](licenses/toolchain/rust/COPYRIGHT-library.html), com os textos da pasta `licenses` da distribuição. Os avisos Debian de MinGW, GCC runtime e binutils estão em `licenses/toolchain/mingw`, incluindo os textos comuns referenciados por esses avisos. Os arquivos abrangem os pacotes de ferramentas; sua inclusão não afirma que toda ferramenta foi incorporada ao CPU Express.

O copyright do pacote GCC inclui o texto da GCC Runtime Library Exception. Os documentos originais foram mantidos completos, sem substituir as condições por um resumo.

## Reproduzir o inventário

```bash
cargo metadata --locked --format-version 1 --filter-platform x86_64-pc-windows-gnu > cargo-metadata-windows.json
python3 scripts/collect-licenses.py --metadata cargo-metadata-windows.json --fetch-missing \
  --source-overrides scripts/license-source-overrides.json \
  --rust-doc-dir <toolchain>/share/doc/rust --rust-version 1.100.0 \
  --mingw-doc-dir <mingw>/usr/share/doc --common-licenses-dir /usr/share/common-licenses
```

Python 3.11 ou posterior. O script não compila nem instala pacotes; lê o metadata fornecido, confere Cargo.lock e copia os avisos. `--fetch-missing` permite buscar somente os textos faltantes em fontes upstream fixadas por revisão. Os caminhos de toolchain são argumentos, sem dependência de um diretório pessoal específico.
