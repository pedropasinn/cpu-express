## Histórico — Telas da E5

45 renderizações headless do egui, em 704 × 676, produzidas pelo exportador `export_expansion_menus` da fonte desta entrega. Não são capturas de uma janela no compositor Windows. Perfil de demonstração; nenhum acesso ao perfil real.

Os índices dos arquivos começam em zero. Páginas acima do último índice disponível são limitadas pelo paginador; a disponibilidade de marcos depende da posse. Imagens com `vazio`, `oferta`, `bloqueado`, `devolucao`, `ativo`, `livre` ou `flutuante` exercitam estados específicos.
