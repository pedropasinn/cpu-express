CPU EXPRESS 0.1.0 — WINDOWS x64

1. Extraia o ZIP para uma pasta e abra cpu-express.exe.
2. Aguarde aproximadamente um segundo para a primeira leitura válida de CPU.
3. Arraste uma área livre da paisagem para mover a janela.
4. Use o botão de opções para CPU manual, métricas e reposicionamento.
5. P alterna sempre no topo; − minimiza; × fecha. Com foco, M alterna métricas.
   Esc fecha as opções ou, quando elas estão fechadas, encerra o aplicativo.

CPU de 0%, 50% e 100% corresponde a alvos fictícios de 12, 56 e 100 km/h.
A velocidade muda suavemente. O modo manual não gera carga no processador.

Destino: Windows 10 versão 1607 ou posterior / Windows 11, x64.
É necessário um driver gráfico com OpenGL 2.0 ou posterior.
O aplicativo é portátil, sem instalador nem assinatura digital.
Não precisa de Rust, navegador, servidor, conta ou conexão de rede para abrir.

Esta entrega foi compilada para Windows GNU x64. Os 27 testes de lógica e os
ensaios gráficos foram executados em Linux; a abertura e a integração efetiva
no Windows ainda precisam de validação no computador de destino.

README.md contém instruções, controles e configuração.
docs/VALIDATION.md separa execução, testes e compilação cruzada.
docs/BENCHMARKS.md apresenta as medições reais e suas limitações.
docs/REPOSITORY_COMPARISON.md compara os cinco projetos investigados.
docs/APRENDER_RUST.md explica o código e propõe experimentos.
scripts/measure-windows.ps1 mede o processo sem criar carga artificial.
O pacote de código-fonte contém Cargo.toml, Cargo.lock, módulos e testes.
