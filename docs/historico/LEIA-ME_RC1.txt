CPU EXPRESS 0.2.0-rc.1 — CINCO FRENTES CONSOLIDADAS

1. Extraia o pacote inteiro para uma pasta no Windows 10/11 x64.
2. Abra cpu-express.exe. Rust não é necessário para usar o programa.
3. Para conhecer os controles sem ler CPU/RAM reais, abra Iniciar_DEMO.cmd.

A janela fica perto da barra de tarefas; não é inserida dentro dela.

Espaço: pausar/seguir. M: HUD. P: sempre no topo. O: opções.
F1: ajuda. R: reposicionar. Esc: fechar painel. Ctrl+Q: sair.
Arraste uma parte livre da paisagem para mover a janela.

Opções: Trem / Viagem / Visual / Janela.
Ocultar na bandeja é diferente de Sair. Recupere a janela pelo ícone do
CPU Express na área de notificação; minimizar usa a barra de tarefas.

O progresso da viagem e as conquistas reiniciam ao fechar o aplicativo.
Preferências de janela, HUD, FPS, cenário, clima e vagões são salvas em
%LOCALAPPDATA%\CPU Express\config.json.

Esta candidata foi compilada para Windows x64 a partir do código consolidado.
Testes de lógica/interface foram executados no host Linux. Não houve execução
do aplicativo em Windows real nem em Wine nesta consolidação: o ambiente
disponível bloqueia o display gráfico. O executável não possui assinatura digital.

Para validar no seu PC, siga docs/windows_checklist.md. A evidência atual fica
em BUILD-INFO.json e docs/VALIDATION.md. Resultados antigos não comprovam este exe.

As licenças das dependências acompanham o pacote. O programa não necessita
de conexão com serviço online nem cria carga artificial para simular CPU.
